          About

          A read-only view of a research project that looks for ships in Sentinel-1 radar images of the Baltic and checks them against AIS. A listed vessel is on a published sanctions or watch list; that is not a finding that it is doing anything wrong now. A dark candidate is a lead, not an accusation. Code and write-up: github.com/pezeonyim/baltic-dark-vessel-detection.

          AIS: aisstream.io; Source: Fintraffic / digitraffic.fi, license CC 4.0 BY. Radar: Copernicus Sentinel-1 data. Watchlist: OpenSanctions.
